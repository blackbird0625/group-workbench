# 小组作业工作台 · Group Workbench

> A customizable collaboration workbench for student group projects — 面向中国高校小组作业的协作工作台模板。


一个为小组作业设计的协作工作台模板：**任务看板、交付文档（版本管理 + 划线批注）、资料库、公告区、文献汇总（共同审稿）、审议意见**，全部集成在一个页面里。

- 前端：纯 HTML/CSS/JS，无构建步骤、无框架依赖
- 后端：附零依赖 Node.js 参考实现（`server.js`，数据存 `data/state.json`）；也可按 [API.md](./API.md) 对接任意后端（Python / Go / 云函数 / Supabase 均可）
- 定制：**第一个打开的人走一遍初始化向导**（像装系统），功能模块、任务分类、权限规则全部点选决定

## 🚀 快速开始（3 分钟跑起来）

```bash
git clone https://github.com/blackbird0625/group-workbench.git
cd group-workbench
node server.js
```

然后浏览器打开 **http://localhost:3000** —— 第一个打开的人会进入初始化向导，配置完名称、模块、分类、成员，就能开始用。

> 没装 Node.js？去 [nodejs.org](https://nodejs.org) 下载 LTS 版，一路 Next 即可。
> 完全没碰过命令行、想部署给别人用？看 [DEPLOY.md](./DEPLOY.md)（保姆级教程，含图解）。

**想让组员也连上来？**

- **同一 WiFi 下**：组员浏览器输入 `http://你的IP:3000`（你的 IP 用 `ipconfig` 查，形如 `192.168.x.x`），防火墙放行 3000 端口即可
- **不同网络/想让任何人都能访问**：把项目部署到免费云平台（Render），拿到 `https://xxx.onrender.com` 发群里——完整步骤见 [DEPLOY.md](./DEPLOY.md) 方案二

## 像装系统一样初始化

后端跑起来后，第一个打开页面的人会进入 6 步向导：

1. **基本信息** — 工作台名称、副标题、管理员称呼（组长/队长/负责人随你定）
2. **功能模块** — 勾选需要的功能（资料库 / 公告区 / 文献汇总 / 审议意见；总览和任务看板常驻）
3. **权限设置** — 逐项决定哪些操作仅管理员可用、哪些开放给所有成员（新建任务、验收、发布公告……全部由你定）
4. **任务分类** — 自定义看板分类（颜色自动分配）
5. **资料分类** — 自定义资料库分类
6. **成员与管理员** — 填写成员名单，勾选谁有管理权限（支持多管理员）

每一步都提供**预设方案**可一键套用（如功能模块的「全套 / 极简 / 文献型」、权限的「组长集权 / 民主协作 / 高度自治」），套用后仍可逐项自定义。

初始化只有一次，配置保存在服务端、跟随数据走。之后每位成员首次登录**自己设置 PIN（密码）**——密码权限完全在个人手里，管理员只能重置、不能查看或代设。

## 功能一览

| 模块 | 说明 | 可关闭 |
|---|---|---|
| 总览 | 我的任务、待认领、待处理意见、最新公告 | 核心 |
| 任务看板 | 五状态流转：待认领 → 进行中 → 待审核 →（需返工 ⇄ 进行中）→ 已完成 | 核心 |
| 交付文档 | Markdown 撰写、版本历史、选中文字划线批注 | 核心 |
| 资料库 | 分类上传文件（限 6MB），大文件建议放网盘贴链接 | ✅ |
| 公告区 | 可置顶的公告（谁能发由权限设置决定） | ✅ |
| 文献汇总 | 提交题目自动查重，全员 👍/👎 投票 + 审稿评论，采纳后一键导出清单 | ✅ |
| 审议意见 | 对任务安排本身的建议，管理员标注采纳/不采纳 | ✅ |
| 使用说明 | 内置操作指引与 FAQ（登录后点侧栏"使用说明"） | 核心 |

其他能力：每 12 秒多设备自动同步、DDL/周日进度/待办提醒、全量备份与恢复（JSON 文件，含附件）。

## 注意事项

- 本项目面向小组内部使用，**未做公网级防爬、限流**，请勿在高流量公开场景裸奔；PIN 用于防止组内冒名，不是银行级安全
- **单进程运行**：server.js 数据在内存合并、延迟写盘，请勿用 pm2 的 cluster 多进程模式启动（多进程互相覆盖会损坏数据）；单进程 + 正常关机，数据不会丢
- 公网部署时：免费云平台磁盘多为临时存储，**请养成勤备份的习惯**（管理员登录后右上角 📥 备份，下载 JSON 存好）；恢复用 📤 恢复
- 登录接口无限流，PIN 请勿使用 1234 这类常见组合；公网部署建议自行加失败次数限制
- 上传的附件以 base64 存在数据里，因此单文件限 6MB；数据量大时可参照 API.md 改为对象存储
